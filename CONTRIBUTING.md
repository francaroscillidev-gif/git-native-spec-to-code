# Contributing Guidelines

Thank you for your interest in contributing to **Git-Native "Spec-to-Code" Verification Agent**!

## Code of Conduct
This project adheres to the Contributor Covenant. By participating, you are expected to uphold this code.

## Development Workflow
1. Fork and clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the automated test suite:
   ```bash
   npm test
   ```
4. Run formal verification on sample specifications:
   ```bash
   npm run verify
   ```
5. Ensure all commits adhere to clean semantic formatting. All PRs will be automatically verified by the formal verification action.
