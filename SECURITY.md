# Security Policy

## Supported Versions
| Version | Supported |
|---|---|
| 9.x (Pinnacle) | :white_check_mark: |
| < 9.0 | :x: |

## Reporting a Vulnerability
We take the security of our verification engine and supply-chain dependencies seriously.

If you believe you have discovered a vulnerability, please DO NOT open a public GitHub issue. Instead, report it directly to the lead maintainer:
- **Contact**: Franca Roscilli
- **Email**: [francaroscillidev@gmail.com](mailto:francaroscillidev@gmail.com)
- **Subject**: `[SECURITY VULNERABILITY] Git-Native Spec-to-Code`

You will receive an acknowledgment within 24 hours. Valid security reports will be patched promptly with an advisory credit.
